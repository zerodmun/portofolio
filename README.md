# Muhammad Munir Akromin — Product Designer Portfolio

A modern, editorial, and minimal personal portfolio website for **Muhammad Munir Akromin**, Product Designer & UI/UX Designer.

Built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## ⚡ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server & Client Components)
- **Language**: TypeScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Typography**: [Geist](https://vercel.com/font)
- **Animation & Motion**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

## ⚙️ Configuration

External links (Dribbble, Behance, LinkedIn, Email) are centralized in `src/data/socialLinks.ts`:

```typescript
export const socialLinks = {
  dribbble: "https://dribbble.com/your-username",
  linkedin: "https://linkedin.com/in/munirakromin",
  behance: "https://behance.net/your-username",
  email: "munirakromin@gmail.com",
};
```

Update this single file to update links across the navigation, gateways, contact section, and footer.
